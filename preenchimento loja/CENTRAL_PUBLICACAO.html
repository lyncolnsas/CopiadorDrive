1. Único Propósito (Single Purpose)

Aba Privacidade
Descrição do único propósito Máx 1.000 caracteres
Gerenciar, clonar e gerar catálogos HTML interativos de pastas e arquivos compartilhados do Google Drive diretamente para a conta do usuário via Google Drive API de forma rápida e segura.

2. Justificativas de Permissões

Permissions Justification
storage
Utilizada para salvar localmente no navegador o progresso da cópia, o histórico de catálogos gerados e as configurações do usuário, permitindo restaurar o estado da operação.
alarms
Utilizada para manter o Service Worker ativo durante a clonagem de pastas grandes e indexação de catálogos, garantindo que o processo não seja interrompido pelo navegador.
identity (OAuth2)
Necessária para obter o token de acesso OAuth2 oficial e seguro do usuário diretamente via Google Identity API (chrome.identity.getAuthToken) para autenticar com as APIs do Google Drive.
downloads
Utilizada exclusivamente para salvar o arquivo de catálogo HTML gerado (.html) diretamente no computador do usuário quando ele clica no botão de download.
unlimitedStorage
Permite armazenar logs detalhados e cache da árvore de diretórios ao indexar pastas que contenham milhares de arquivos e subpastas.
Correspondência de Host: *://drive.google.com/*
Utilizada exclusivamente para injetar um botão flutuante inteligente (FAB) na interface web do Google Drive, permitindo clonar ou catalogar a pasta aberta diretamente na tela.
Correspondência de Host: https://www.googleapis.com/*
Utilizada pelo Service Worker em segundo plano para fazer requisições HTTP REST diretas aos endpoints oficiais da Google Drive API v3 para listar, ler, criar e duplicar arquivos e pastas.
