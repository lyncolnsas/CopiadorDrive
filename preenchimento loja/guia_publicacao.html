🚀 Guia Oficial de Deploy

Como Publicar na Chrome Web Store

Passo a passo completo para cadastrar suas credenciais no Google Cloud, empacotar a extensão e publicar com aprovação rápida na Loja do Chrome.

✨ Experiência 1-Clique para o Usuário Final

A extensão já foi adaptada para usar o chrome.identity.getAuthToken. Isso significa que o usuário que baixar da loja NUNCA precisará abrir o Google Cloud, nem colar chaves API. Ele clica em "Conectar com Google", autoriza em 1 clique e usa normalmente.

1
Criar o Rascunho e Obter o ID na Loja

Antes de gerar as chaves no Google Cloud, precisamos registrar o rascunho na loja para obter o ID oficial de 32 letras da extensão:

  1. Acesse o Chrome Developer Dashboard:
    Abrir Chrome Developer Dashboard ↗
  2. Se for sua primeira vez, pague a taxa única de registro de desenvolvedor do Google ($5 USD).
  3. Clique no botão azul "Novo item" (New item).
  4. Faça o upload de um arquivo .zip qualquer da extensão para criar o item.
  5. NÃO publique ainda. Na página do item, localize e copie o ID da Extensão (código de 32 letras minúsculas, ex: ammibafhnmcbbjphdlfldimjimfglhec).
2
Configurar OAuth no Google Cloud (Nova Tela "Google Auth Platform")

Acesse o Google Cloud Console para autorizar a extensão a se comunicar com a Google Drive API:

Abrir Google Cloud Console ↗

💡 Dica: Se ainda não ativou a API, digite "Google Drive API" na barra de pesquisa no topo da página e clique no botão azul "Ativar".

No menu lateral esquerdo da tela "Google Auth Platform", siga estas 4 etapas:

  1. 1. Branding (Marca / Tela de Consentimento):
    • Nome do app: Copiador de Drive
    • E-mail de suporte do usuário: Selecione seu e-mail.
    • Página inicial do aplicativo:
      https://lyncolnsas.github.io/CopiadorDrive/
    • Link da Política de Privacidade do aplicativo:
      https://lyncolnsas.github.io/CopiadorDrive/privacy.html
    • Link dos Termos de Serviço: (Opcional - pode deixar em branco ou colar o link da privacidade).
    • Domínios autorizados:
      • Mantenha: chromiumapp.org
      • Clique em + Adicionar domínio e cole:
        lyncolnsas.github.io
        ⚠️ Atenção: Use seu subdomínio completo (lyncolnsas.github.io) e não apenas github.io, pois o Google rejeita domínios compartilhados.
    • Dados de contato do desenvolvedor: Digite seu e-mail.
    • Clique em Salvar.
  2. 2. Público-alvo:
    • Certifique-se de que o tipo de usuário está configurado como Externo.
  3. 3. Acesso a dados (Escopos da API):
    • Clique no botão "Adicionar ou remover escopos" (uma janela lateral abrirá à direita).
    • Você pode adicionar de duas maneiras:
      👉 Método 1 (Mais Rápido - Colar Manualmente):

      Role até o final da janela lateral direita até o campo "Adicionar escopos manualmente", cole os dois escopos e clique em "Adicionar à tabela":

      https://www.googleapis.com/auth/drive.readonly
      https://www.googleapis.com/auth/drive.file
      👉 Método 2 (Buscar na Lista):
      1. No campo de filtro/pesquisa no topo da tabela, digite drive.readonly e marque a caixa de seleção correspondente.
      2. Depois digite drive.file e marque a caixa de seleção correspondente.
    • Após selecionar ambos, role até o final da janela lateral e clique no botão azul "Atualizar" (ou "Salvar e continuar").
  4. 4. Clientes (Gerar o Client ID):
    • Clique no botão "+ CRIAR CLIENTE" no topo.
    • Tipo de aplicativo: Selecione Extensão do Chrome (Chrome Extension).
    • Nome: Copiador de Drive
    • ID do item: Cole o ID de 32 letras que você obteve na Chrome Web Store na Etapa 1.
    • Clique em Criar.
    • 📋 Copie o ID do Cliente gerado (código que termina com .apps.googleusercontent.com).
3
Atualizar o Client ID no manifest.json

Abra o arquivo manifest.json e cole o Client ID gerado na linha "client_id":

"oauth2": {
  "client_id": "SEU_CLIENT_ID_DO_GOOGLE_CLOUD.apps.googleusercontent.com",
  "scopes": [
    "https://www.googleapis.com/auth/drive.readonly",
    "https://www.googleapis.com/auth/drive.file"
  ]
}
💡 Dica: Se você estiver usando a chave RSA fixa atual, o Client ID já pode ser vinculado diretamente ao ID atual da extensão.
4
Empacotar o Arquivo .zip Final

Selecione os arquivos da extensão e compacte em um arquivo .zip. Preste atenção no que deve e no que NÃO deve ser incluído:

✅ manifest.json
✅ background.js
✅ popup.html / .css / .js
✅ tab.html / .js
✅ content.js / .css
✅ Pasta icons/ (16, 32, 48, 128)
❌ app.json (não incluir)
❌ client_secret_*.json (não incluir)
❌ genkey.js / .md (não incluir)
⚠️ Atenção: Compacte os arquivos diretamente na raiz do .zip, e não dentro de uma subpasta.
5
Enviar para Revisão na Chrome Web Store

Com o pacote pronto, conclua os detalhes da listagem na loja:

  1. No Chrome Developer Dashboard, faça upload do .zip final gerado na Etapa 4.
  2. Preencha as informações da listagem da loja:
    • Título: Copiador de Drive - Clonador de Pastas
    • Descrição Detalhada: Explique que a extensão clona pastas compartilhadas diretamente no Drive do usuário de forma segura.
    • Categoria: Produtividade / Ferramentas.
  3. Envie pelo menos 1 screenshot demonstrando o funcionamento (resolução recomendada: 1280x800).
  4. Na aba de Privacidade, marque que a extensão utiliza a API do Drive exclusivamente para a função principal e cole o link do seu privacy.html.
  5. Clique no botão azul "Enviar para Análise" (Submit for review).
🎉 Tudo Pronto! A equipe do Google costuma analisar extensões dentro de 24 a 72 horas. Assim que aprovada, sua extensão estará pública e disponível para qualquer pessoa instalar com 1 clique.
