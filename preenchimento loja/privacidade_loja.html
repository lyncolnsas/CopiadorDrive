Aba de Privacidade

1

Único Propósito (Single Purpose)

Descrição do Único Propósito 255 / 1.000 caracteres
A extensão tem como finalidade única e exclusiva permitir que o usuário clone e replique pastas compartilhadas do Google Drive diretamente para o seu próprio Google Drive ("Meu Drive"), garantindo a posse dos arquivos sem necessidade de download manual.
2

Justificativas de Permissão

Copie a justificativa técnica exata para cada uma das permissões declaradas no manifesto:

Justificativa de: identity 269 / 1.000 caracteres
Necessária para autenticar com segurança a conta Google do usuário via OAuth2 nativo (chrome.identity.getAuthToken), obtendo o token de autorização estritamente para executar as chamadas de cópia diretamente na conta do usuário no Google Drive.
Justificativa de: storage 258 / 1.000 caracteres
Utilizada para salvar temporariamente em cache local a estrutura de pastas mapeada durante o processo de cópia. Isso permite retomar cópias interrompidas sem duplicar arquivos e manter o estado da interface se a aba for fechada.
Justificativa de: alarms 248 / 1.000 caracteres
Utilizada para manter o Service Worker (background.js) ativo através de um heartbeat periódico durante operações longas de cópia de pastas volumosas, impedindo que o Chrome finalize o processo em background antes da conclusão.
Justificativa de: unlimitedStorage 247 / 1.000 caracteres
Necessária para garantir que árvores e estruturas de pastas com milhares de arquivos possam ter seu mapeamento em cache salvo localmente no navegador sem risco de bloqueio por limite de cota de armazenamento local.
Justificativa de: Permissão do Host (https://www.googleapis.com/*) 258 / 1.000 caracteres
Necessária para comunicar com os endpoints da Google Drive API v3 (ex: /files, /files/{id}/copy) a fim de ler a árvore de arquivos da pasta compartilhada de origem e criar os arquivos clonados diretamente na conta do usuário.
